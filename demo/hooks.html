Foundation hooks

The baseline's two color hooks, which no profile declares: each falls back to a hue of the palette, and a consumer sets one on any subtree.

Interaction: --interaction-color

What you can act on, by default --blue: links, checkboxes, radios, ranges, the focus outline, the caret, and selected text.

A link

Accent: --accent-color

What is current, active, or in progress, by default --magenta: native progress, at a value and indeterminate.

Overrides

Each row sets one hook on its own subtree, and only that hook's elements follow: the accent on progress alone, the interaction color on everything else.
